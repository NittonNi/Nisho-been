How to set up your database
  1. Go to airtable.com and create a base called Nisho
  2. Create table Journeys with fields: ID (text), From (text), To (text), Transport (text), Date (date), Days (number), Notes (long text)
  3. Create table Stops with fields: JourneyID (text), City (text), Country (text), Arrival (date), Departure (date), Hotels (long text), Airports (long text)
  4. Create table Wishlist with fields: Country (text), Code (text), Note (long text)
  5. Get your Personal Access Token at airtable.com/create/tokens (scopes: data.records read + write)
  6. Find your Base ID in the URL when you open the base: airtable.com/appXXXXXXXX/...
